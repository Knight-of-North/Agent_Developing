# 启动封面设计说明（2026-11）

> 对应实现：`ui_launch.py`；入口编排：`app.py` 的 `if not st.session_state.launched:`。

## 目标

启动项目时先给玩家一个"进入故事"的仪式感，而不是直接抛出设定表单：

1. **氛围先于信息**：先看到深夜档案室的顶灯、夜雨、雾和尘埃，再看到游戏名；
2. **动作有叙事含义**：中央不是普通按钮，而是一枚火漆印章——点击 = 启封卷宗；
3. **不打断原有流程**：点击「开始游戏」后才进入现有开始页（案件设定），原有表单、侧栏、玩法说明全部不变；
4. **刷新即重播**：启动封面靠 `st.session_state.launched` 控制，浏览器刷新/重新打开会重新播放，方便演示。

## 页面结构

```
启动封面（fixed 全屏覆盖）
├── 场景层：吊灯 / 光锥 / 夜雨拱窗 / 雾 / 尘埃 / 闪电 / 胶片颗粒 / 暗角
├── 画框层：双层金线 + 四角标记 + 顶部档案编号
└── 内容层：英文 eyebrow → 主标题 → 分隔饰线 → 标语 → 数据点 → 火漆按钮 → 提示
```

## 动画时间线

| 时间 | 内容 |
|---|---|
| 0.0s | 场景淡入，吊灯闪烁点亮（模拟通电） |
| 0.5s | 英文 eyebrow 上浮淡入 |
| 0.6s–1.9s | 主标题从模糊/宽字距收拢到清晰金色 |
| 1.15s–1.6s | 分隔饰线、主标语、副标语、数据点依次浮现 |
| 1.75s | 火漆印章从放大 + 旋转"盖"下来，外圈开始呼吸脉冲 |
| 2.35s | 「点击封印 · 启封卷宗」提示浮现 |
| 持续 | 雨丝下落、雾漂移、尘埃上浮、偶尔远处闪电 |

`prefers-reduced-motion: reduce` 时所有动画瞬时完成，内容直接可见。

## 实现要点

- `st.container(key="launch_screen")` 用 `position: fixed; inset: 0; z-index` 覆盖 Streamlit 主区域与顶栏；
- 场景全部为 CSS 渐变 / 遮罩 / keyframes，无外部图片和音频素材，零额外请求；
- 中央按钮是原生 `st.button`，键盘可访问；点击后设置 `st.session_state.launched = True` 并 rerun；
- 启动封面不依赖游戏图状态，不触碰 `graph / nodes / validators`，对业务零改动。
